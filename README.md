# Tick-Tock Boutique

A clock-reading game for Margot. Read analogue clocks to earn stars, then spend them on outfits, hair, make-up, wings and places for a manga-style doll.

Play: https://anmacmillan.github.io/tick-tock-boutique/

- Five levels: o'clock, half past, quarter past and to, five minutes, every minute. Each starts with an animated lesson.
- Three kinds of question: read the clock, set the clock by dragging the hands, and pick the right clock.
- Short pink hand = hour, long blue hand = minutes. Help shows the minute numbers and the "past" and "to" halves.
- Every sound and the music-box tune are made in the browser; times are read aloud.
- Progress is saved on the iPad. Add `?name=Someone` to the link to change the name.
